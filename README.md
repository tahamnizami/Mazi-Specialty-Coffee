# Mazi Specialty Coffee

A single-page, responsive café website built from the provided GitHub Copilot website specification.

## Project structure

- `index.html` — page structure and content
- `css/style.css` — custom branding, layout, and responsive styling
- `js/script.js` — navigation, menu filtering, lightbox, reveal animations, and form validation
- `assets/images/` — placeholder local asset paths for future photography

## Notes

- The design follows the warm editorial café direction described in the specification.
- Placeholder images and contact numbers are clearly marked with TODO comments for later replacement.
- The reservation form is a front-end demo state and intentionally does not claim a confirmed booking.

## Run locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
